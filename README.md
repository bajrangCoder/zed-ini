# zed-ini

Support for `ini` and related config files (ini, conf, cfg, config, editorconfig), systemd unit files (automount, mount, path, scope, service, slice, socket, swap, target, timer), and podman quadlet files (container, volume, network, kube, image, build, pod)

## Grammar

- [tree-sitter-ini](https://github.com/justinmk/tree-sitter-ini)
